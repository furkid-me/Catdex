# CatDex 🐈

Collect the cats of the world.

Mobile-first MVP for a daily real-cat sticker exchange: create your cat, take one daily snap, turn it into a sticker, swap with a stranger, and grow a global CatDex.

## MVP
- My Cats
- Daily Snap / Sticker
- Random Swap demo
- World CatDex
- Collection
- Household / mixed-breed friendly taxonomy

## Run
```bash
npm install
npm run dev
```

Current build uses demo data and emoji placeholders so the complete interaction loop can be tested before adding authentication, photo storage, image processing, moderation and real matchmaking.
